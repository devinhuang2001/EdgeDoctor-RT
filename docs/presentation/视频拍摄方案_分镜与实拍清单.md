# EdgeDoctor-RT 参赛视频拍摄方案

目标时长 **4 分 30 秒**（赛事要求 3~5 分钟，见设计文档 9.1）；另附 3 分钟精简剪辑表。
拍摄分两批：**板端实拍**（你要补的）+ **PC 端素材**（已录好，可直接剪进去）。

---

## 一、先解决三件事，再开机

### 1. 板上得有一个能回放的 `.edgp`

现在仓库里只有三个文件，全是测试夹具：

| 文件 | 大小 | 性质 |
| --- | --- | --- |
| `artifacts/board/synthetic_smoke_2s.edgp` | 113 KB | **合成信号**，2 秒，约 3 帧推理 |
| `artifacts/board/corrupt_crc.edgp` | 1.2 KB | CRC 错误，用来演示拒绝 |
| `artifacts/board/truncated.edgp` | 100 B | 截断包，用来演示拒绝 |

10-02 验收时板上的那份已经被删掉了（为释放配置保存空间），**录制前必须重新传一次**：

```powershell
# 板端先进接收态
msh /> ry /flash/synthetic_smoke_2s.edgp
# PC 端发送（串口按实际改）
python scripts\board_ymodem_send.py --port COM21 --baud 115200 --file artifacts\board\synthetic_smoke_2s.edgp
```

**要提前想清楚的话术**：这条是合成信号，只能证明链路通，不能证明精度。
设计文档 9.2 和 PPT 第 15 页（Demo）自己就写了「演示报警可使用合成回放，但必须明确标注」——按这个口径讲，别含糊。

> 想用 KAIST 真实记录做回放包，得先过 `validate_dataset.py` 的配对校验。而 `docs/data-pipeline.md` 已经写明：KAIST v6 同名声学与振动文件录制日期不同、声学只覆盖五个零负载条件，**校验会拒**，且"不得为正式验收绕过"。所以录视频这一轮不要在这上面耗时间，按合成回放 + 明确标注走。

### 2. 确认板子起来后 `edgeimu` 是活的

```text
edgeimu info
edgeimu sample
edgeai info
```

三条都要有正常输出再开拍。`edgeai info` 会打出 `backend= / bytes= / frames= / p50 / p95 / drops=`，这是全片最关键的一条证据（见第四节）。

### 3. 决定要不要拍 PC 端

已有的 51 秒 PC 控制台素材（`EdgeDoctor-RT_演示素材_20261031`）可以用，但它演示的是**服务端 + 桌面控制台**，不是板子。两者在同一支视频里出现，必须用字幕把关系说清楚，否则评委会以为板子把画面投到电脑上了。

建议：**板端 3 分钟为主，PC 端 1 分钟作"证据与留痕"补充**，中间用一句转场词切开。

## 二、分镜表（4 分 30 秒）

| 镜号 | 时间 | 画面 | 关键动作 | 口播（照念） |
| --- | --- | --- | --- | --- |
| S1 | 0:00–0:18 | 板子通电，屏幕亮起停在「概览」页，轻微推镜 | 手指按下复位 | 这台板子不联网，也能告诉你机器坏在哪。 |
| S2 | 0:18–0:45 | 板卡＋电机同框，手指点 IMU 贴片 | 手指沿信号路径划一下 | 旋转设备坏之前，振动先变。云端看不及时，人耳听不出来，我们把判断放在设备旁边。 |
| S3 | 0:45–1:10 | 板卡接口特写 → 串口启动日志 | 复位抓首屏 | PSOC Edge E84，Cortex-M55，跑 RT-Thread。启动完就自己开始采样，不用人点。 |
| S4 | 1:10–1:40 | HMI「概览」页特写 | `edgeimu info` → `edgeimu sample` | 板载 IMU 208 Hz 连续采，20 毫秒一个固定块，1 秒一个分析窗，半秒更新一次诊断。 |
| S5 | 1:40–2:15 | HMI 逐页切换 | `edgeui tab 1` `2` `3` `4` `5` | 六个页面回答六个问题：现在健不健康、信号长什么样、出过什么事、趋势怎么走、设备是谁、连没连上。 |
| S6 | 2:15–2:40 | 回放跑起来，数值跳动 | `edgeai replay /flash/synthetic_smoke_2s.edgp` | 这是合成信号回放，验证的是链路通不通，不是精度。精度后面用记录级留出测试说。 |
| S7 | 2:40–3:00 | 告警演示（红色） | `edgeui alarm` → 停两秒 → `edgeui ack` | 报警会一直亮着，直到有人确认。确认动作进事件记录，不是点掉就没了。字幕：演示触发 |
| S8 | 3:00–3:30 | 串口 `edgeai info` 全屏可读 | 照打 | 这段是实打实的板端数字：模型 2508 字节，预处理和推理的 P50、P95，丢帧数。 |
| S9 | 3:30–3:50 | 切 PC 控制台（全屏录屏） | 播已有素材 | 板子把事件和遥测同步到局域网里的控制台，维修班长在电脑上看的是同一份状态。 |
| S10 | 3:50–4:10 | 训练图表：混淆矩阵、LOLO 柱状 | PPT 第 7、9、13 页，或 `artifacts/training/*.png` | 测试集 96.5，四类故障零漏检；换成没见过的 4 Nm 负载，掉到 77.88。这个数字比平均分有用。 |
| S11 | 4:10–4:30 | 回到板子，定格 | 无 | 现在是振动单模态、Reference C。下一阶段是现场数据校准、CMSIS-NN 和 U55 加速。边界先讲清楚，比分数重要。 |

**S6 的替代拍法**：如果开机后回放跑不起来（文件没传进去、CRC 校验失败），就直接跳过 S6，把 S4 的实时采样拉长到 40 秒。**不要用假画面填**，缺一段比造假强。

## 三、机位与光线（实拍最容易被扣分的地方）

### 机位

- **A 机（主机位）**：三脚架，正对板子，45° 俯角；画面里同时有板卡、屏幕、串口窗口。这是"同框证明"，9.2 第一条要求。
- **B 机（特写）**：手机手持，拍手指操作、IMU 贴片、屏幕内容变化。用于跳切，掩盖剪辑点。
- **串口**：不要用手机拍显示器。**直接录屏**（`putty` / `MobaXterm` 窗口录制，或 OBS 窗口捕获），后期做画中画贴在右下角，白色等宽字体，字号调到串口窗口能放 8 行。

### 光线

- 关掉顶灯直射，用一盏侧后方柔光（或窗光）打板子，避免屏幕反光。
- 屏幕亮度调到 80% 以上，**不要全亮**（会过曝）。
- 屏幕摩尔纹：机位与屏幕成 **15~20° 夹角**，不要正对；相机对焦锁在屏幕文字上；能上偏振镜最好。

### 声音

- 口播单独录（手机贴着录或领夹麦），后期配音，别用现场同期声（风扇声太大）。
- 语速控制在每分钟 200 字左右，4 分 30 秒全片口播约 700~750 字。

## 四、这条视频能顺手补掉一项提交缺口

提交检查表里「正式板端性能：待补 / ≥200 热样本；输出 P50/P95 与丢帧」一直空着。

`edgeai info` 打印的就是这个：

```text
clock=dwt frames=<帧数> preprocess_p50_us=.. preprocess_p95_us=..
inference_p95_us=.. total_p95_us=.. drops=<丢帧>
log=/flash/edgedoctor.csv queued=.. written=.. dropped=.. errors=..
```

**做法**：录 S8 之前，先用 `edgeai replay ... fast` 把帧数跑到 200 以上（`frames=` 到了就行），然后打 `edgeai info`，把这一屏截下来存成 PNG。

这一屏同时满足三件事：视频里的硬证据、检查表的"正式板端性能"、答辩被问时能直接调出来。

⚠️ 注意：`fast` 模式是尽快跑完，不是实时节拍。**报数字时必须写清楚是快跑还是实时**，别混着说。

## 五、剪辑

### 结构

```
钩子(0:18) → 问题(0:27) → 硬件(0:25) → 功能(1:30) → 性能(0:30) → PC补充(0:20) → 证据(0:20) → 边界(0:20)
```

### 硬性要求

- **全程横屏 1080p**，25 或 30 fps，导出 H.264。
- 关键命令**保留完整上下文**（命令 + 输出至少留 2 秒），不要一闪而过。
- 屏幕上一切非实测内容都打字幕：
  - 合成回放 →「合成信号回放 · 验证链路」
  - 告警演示 →「演示触发 · 非真实故障」
  - 图表 →「记录级留出测试 · 2026-09-03」
- 不加背景音乐，或只加极轻的环境垫底（-28 dB 以下）。技术类评审不喜欢 BGM 盖住口播。

### 片头片尾

- 片头 3 秒字幕卡：项目名 + 一句话 + 「PSOC™ Edge E84 · RT-Thread」
- 片尾 5 秒：项目名 / 仓库地址 / 文档版本号，静止 3 秒以上方便截图

## 七、五条红线

1. **不说"全 INT8 网络"**。当前是静态 Q7 权重量化，第一层 INT32 累加，输出层保留浮点缩放。
2. **不说"已启用 U55"**。Reference C 是当前后端，U55 是平台能力与下一阶段。
3. **不说"2508 字节固件"**。那是模型参数体积，不是固件大小。
4. **不把合成回放说成真实传感器推理**。回放就是回放，字幕必须标。
5. **不说"全部验收通过"**。10-02 实板验收里 MQTT 启动突发稳定性没通过，这句话说出来就是硬伤。

## 九、和已有 PC 素材怎么接

`EdgeDoctor-RT_演示素材_20261031\01_视频\` 里那支 51 秒是**桌面控制台**，不是板端。用法：

- **放在 S9**（3:30–3:50），做全屏切换，配字幕「局域网控制台 · 与板端同一份状态」
- 或做**画中画**：板子画面为主，右下角小窗放控制台的四页切换，证明"两端看的是同一份数据"

**不要**把它放在开头。开头必须是板子，否则整支片子会被判成"PC 演示"。
