# V2 实施增补：参赛优化

2026-09-07：用户授权实施 V2 全部软件及引用《优化嵌入式项目》中的应用增强。实板、手机、标定和长稳证据独立于软件完成度。引用中的 NPU/M33 是条件扩展，本次仍按 M55 完成；不增加自动停机、寿命预测、泛化聊天。

## 新增可执行合同

| ID | 行为 | 验收 |
|---|---|---|
| OPT-01 | 操作员选择工况后进入过渡态，最多30秒；连续4个有效输出且RMS最大/最小≤1.15才启用对应基线；没有匹配基线显示原因。禁止自动选择最近基线宣布正常；不输出RPM | 边界30秒、无基线、质量中断、异常持续均测试；过渡不恢复已有报警 |
| OPT-02 | 同设备/安装/工况/基线的有效窗口累计EWMA，alpha=0.05；向量RMS有符号标准偏差EWMA≥3连续60个输出产生独立趋势提醒；低于1连续20输出恢复 | 缓慢斜坡、健康噪声、无效窗口、键切换；快速报警与趋势事件互不替代；阈值为待现场校准的开发默认值 |
| OPT-03 | 基线保存重力均值方向；当前与参考向量范数均在0.8..1.2g且夹角>15度连续10输出时提示疑似安装变化并使基线不适用；人工更新安装revision后重建 | 旋转、零向量、冲击、同方向重新安装的不可检测限制；不命名为松动故障 |
| OPT-04 | 维修记录、短时复测与正式30分钟两侧同键对比分开；事件报告可打印/导出HTML和机器可读JSON，包含版本、质量、证据CRC和缺失原因 | 不同工况/安装、有效数据不足拒绝改善结论；HTML转义，报告不更改事件状态 |
| OPT-05 | 人工反馈可选择操作干扰/工况变化/确认异常/无法判断，追加审计和操作者时间；不自动变成五类真值 | 重复提交、权限、标签枚举和审计测试 |
| OPT-06 | PC训练正常簇距离模型：健康标注、训练/校准/留出按运行批次隔离；冻结15维归一化、最多4中心和阈值；M55固定内存推理，默认影子运行，只记录分数/版本 | C/Python黄金对齐；NaN/不匹配/损坏模型拒绝；影子分数不能驱动正式报警；无实采训练数据时无已验证模型 |
| OPT-07 | 有效监测时长、无效窗口比例、最长连续不可判定时长进入快照/遥测/UI；播报每60秒最多占用5秒，含保护时间，超过则减少播报 | 高频语音请求不能无限延长保护；质量检查始终运行；时间倒退/切换工况测试 |
| OPT-08 | 同输入模型/DSP基准和事件级评估工具，记录样本数、版本、耗时分位、误报事件/有效小时和延迟 | 不把窗口准确率当事件检出率；无200热样本不得标正式P95；无配对实测不得宣称优化收益 |

以上默认阈值可配置且版本化。UI在设备页加入工况/安装检查，趋势页加入持续偏移提示，事件详情加入人工复核与检修报告。网页/语音均读取真实快照，不补全不存在的事实。

实施顺序：W1公共状态 → W2采集特征 → W3基线/工况/偏移/安装/影子 → W4存储 → W5 MQTT → W6服务/报告/反馈 → W7 UI → W8语音预算 → W9评估与证据。
