# EdgeDoctor V2 UI 规格

版本0.1，2026-09-06。目标：把设备状态、为什么报警、是否有人处理讲清楚；800×480屏幕可触摸、信息克制、与网页状态一致。

## 1. 视觉方向

主题名“Quiet Instrument / 清晰仪表”。温暖浅灰画布、深墨色固定窄导航、白色内容面、青绿实时曲线与细灰基线、琥珀待处理状态。红色只表达严重报警/失败，不能因为“正在回放”就显示危险红。

页面主要视觉是当前振动值与频谱，而不是装饰性机器大图。保留品牌但缩小到导航头，不用占据半屏的健康度圆环。LIVE_IMU没有可解释健康百分比，因此不展示健康百分数。使用真实数据单位和相对基线倍数。

| Token | 值 | 用途 |
|---|---|---|
| canvas | #F2F4F1 | 页面背景 |
| surface | #FFFFFF | 面板 |
| ink | #172A29 | 主文字/导航 |
| secondary | #586965 | 次要信息，避免过浅 |
| line | #DCE4DF | 边框和分隔 |
| accent | #176B57 | 主按钮/有效状态 |
| accent_soft | #E4F1EA | 选中/基线区域 |
| warning | #9A5A12 / #FFF2DE | 预警/未确认 |
| critical | #B93535 / #FCEBE8 | 严重报警/错误 |
| unavailable | #697671 / #E9EDE9 | 无数据/不适用 |

正文中文16px，辅助标签14px（不能放关键状态/单位），页面标题24px，主数值44–48px，按钮16px半粗。板端复用现有中文字体加载，补字形子集16/20/24与数字48；必须包含“偏离、基线、待同步、未确定、静止、恢复、证据”等。原型系统中文字体仅为预览，验收以板端字形为准。

圆角：面板12px、按钮8px、状态标签6px。细边框1px，不做模糊玻璃、大片渐变或持续扫光。数字等宽对齐；符号/单位紧邻数字但降一级字号。状态必须图标+文字，不能只靠颜色。高危状态不用全屏闪烁。

## 2. 800×480布局合同

固定逻辑尺寸，不通过缩小字体塞更多数据。左导航88px；其余内容宽712px。顶部状态栏高52px，正文从y=64开始，左右边距16px，底部留12px，可用主内容680×404px。正文垂直滚动只允许事件详情/长档案，不允许主页面横向滚动。

左导航logo区域52px；6个入口每个56px，图标20px+中文标签16px，底部设备短ID与模式。入口：总览、信号、事件、趋势、设备、连接。所有按钮有效触摸区≥44×44px；主要按钮高44px。对比线/图标采用2px以上线宽。

顶部：asset名称（最多12个汉字，可点击进入设备页）、数据来源胶囊、质量状态、MQTT状态按钮。右侧时间显示HH:mm；未校时显示“时间未同步”，不显示假时钟。MQTT状态不与传感器在线混为一谈。

主页面顶部报警横幅高52px（出现时压缩/重排正文，不遮挡内容）；包含“振动偏离基线 / 待确认”等说明和“查看事件”44px按钮。新事件默认不自动跳页，避免触摸时操作被劫持；严重报警提示音与导航红点吸引注意。

## 3. 六个主页面

### P01 总览

- 上方结论区：当前诊断“基线范围内 / 振动偏离基线 / 尚未建立基线 / 数据不可用”。下方16px说明来源与窗口年龄。
- 主区域左右约410/258px：左侧主数值“振动 RMS 0.018 g”，次值“基线中位数0.017 g / 偏离1.3”；右侧单个状态面板“采样208 Hz、有效、丢样0、基线B03”。
- 下方一条60秒RMS折线，含基线与固定单位轴，不给不匹配数据画正常区间；图表下显示最近事件摘要，可点击。
- 无基线时主数值仍显示，右侧主按钮“建立基线”；不出现五类标签与百分比。mqtt离线时只改变网络标签和待同步数量，结论不变。

### P02 信号与依据

- 页面上方分段按钮“波形 / 频谱 / 依据”，44px触摸。
- 波形：最近1秒三轴可切换，显示单位g/时间；静止状态仍可查看原始细节。
- 频谱：当前实线青绿、基线虚线灰，5–40Hz、同一物理刻度；固定图例和峰值频率。可用基线不存在时只显示当前曲线及原因。
- 依据：最大偏离3项，显示当前/基线/偏离；底部显示触发规则“连续3次 ≥6，当前2/3”，并标注“故障类型未确定”。
- 下方4个紧凑指标：RMS、峰值、峰值因子、峰度。质量故障时数值变灰、显示年龄，禁止跳到0。

### P03 事件中心

- 筛选条“待处理 / 全部”，待处理包含ACTIVE或UNACKNOWLEDGED；列表每行≥68px，最多4行可见。
- 每行左侧严重度标记，中间事件名/发生时刻与短ID，右侧“待确认 / 已确认·仍异常 / 已恢复·待确认 / 已归档”。列表不把revision当新事件。
- 详情使用右侧宽480px全高抽屉：顶部标题/返回；状态轨迹；发生值、基线、质量；同步/证据状态；底部固定“确认收到”“回放证据”按钮。确认前后按钮位置不变。
- “确认收到”按下立即禁用并显示“保存中”；durable成功才显示确认者/时间。失败显示“确认未保存，请重试”，不能乐观显示成功。已确认时按钮为禁用“已确认”。
- 证据不完整显示“部分片段 7.0 s”；损坏则禁用播放并提供“查看错误”。后台实时监测持续；抽屉标明“正在查看历史，不影响实时监测”。

### P04 趋势

- 时间按钮“1小时 / 24小时”；指标按钮“RMS / 基线偏离”。120个显示点，后台按min/max保留突变，不用均值抹掉尖峰。
- 时间轴标报警三角与维修竖线；触摸点出现48px高数值卡，显示时间、值、有效率。离线/断采缺口留空，用灰色缺口带说明。
- 次入口“维修前后”→选择记录→同工况校验→前后RMS/事件数/有效数据量对比。不匹配则显示不能比较原因，不给改善百分数。
- 板端只保留24小时，超过范围显示“在网页查看长期历史”。

### P05 设备与基线

- 当前机器名称、安装位置、轴方向、工况、传感器profile、当前基线版本；“选择设备”“建立基线”“维修记录”各44px。
- 基线向导4步：设备/安装/工况核对 → 健康运行确认 → 采集60秒 → 预览保存。步骤标题与取消按钮常驻；采集显示有效秒数、剩余时间、质量原因，进度按有效窗口而不是墙钟伪进度。
- 保存预览显示RMS范围、稳定性、60个有效窗口；失败可返回重试，旧基线不丢。重新学习不能由远程语音触发。
- 切换设备后提示旧活动事件仍在历史中，监测使用新设备的匹配基线；切换先停止当前baseline学习，不能跨设备累积。

### P06 连接与系统

- 顶部两块独立状态：Wi-Fi链路、MQTT服务。显示SSID（不显示密码）、IP、Broker主机、连接状态、最近同步、待发revision数量。
- 中部状态轨迹：“本地已保存 → Broker已接收 → 服务已落库”；最终节点仅由应用receipt驱动。
- “发送测试告警”先弹出“仅测试通知链路”说明，测试namespace，设备屏幕和手机标题都带“测试”。测试结果只说明实际达到的阶段，不能自动显示“手机已收到”。
- 诊断折叠区显示CPU/DSP P95、栈余量、存储剩余、日志错误、UTC状态；数值来源真实。证书失败/待发满/存储满各有文字原因。
- Wi-Fi配网复用现有流程；新入口调用现有管理接口。Broker/凭据在部署配置中管理，板端不提供不安全明文密码回显。

## 4. 跨页面状态矩阵

| 状态 | 全局标签 | 主数值/结论 | 可执行操作 |
|---|---|---|---|
| 有效且基线内 | 青绿“实时监测” | 当前RMS + 基线范围内 | 查看趋势/依据 |
| 偏离预警 | 琥珀“振动预警” | 当前RMS + 类型未确定 | 查看/确认事件 |
| 严重偏离 | 红“需要处理” | 当前RMS + 偏离值 | 查看/确认/留证 |
| 无基线 | 灰“待建立基线” | 物理量可见，无法比较 | 建立基线 |
| idle | 灰“静止/振动很弱” | 当前幅值，暂停运行基线判断 | 查看信号 |
| 断线/过期 | 灰+错误标志 | 上次值灰化/年龄，不写正常 | 查看采集错误 |
| MQTT离线 | 网络图标橙，监测状态独立 | 本地结论继续 | 待同步详情 |
| 回放 | 蓝灰“历史回放” | 原事件/原版本，明确模式 | 退出历史 |
| 演示 | 琥珀“演示数据” | 样例数据持续标识 | 退出演示 |

源模式不能通过隐藏菜单才看见。APP默认DEMO关；无数据初始页显示等待传感器。未知异常不显示红色“外圈故障92%”。

## 5. 语音交互

总览右上提供44px“语音”入口，打开底部400×160px面板，显示“你可以问：当前状态/最近报警/处理建议”。输入中/查询中/播报中/离线分别有文字状态。结果文本保留snapshot时间和来源，语音说过期时屏幕同步显示。

播报音量复用XiaoZhi设置，不为每个报警自动升到最大。污染窗口保护期显示小标签“播报中·基线学习暂停”；不通过整屏动画干扰报警阅读。

## 6. LVGL落地与性能

新建ui/ed_ui_tokens.h、ed_ui_vm.[ch]、ed_ui_widgets.[ch]、ed_ui_overview.c、ed_ui_signal.c、ed_ui_events.c、ed_ui_trends.c、ed_ui_asset.c、ed_ui_connection.c。edgedoctor_ui_init/process保留为集成入口；原UI报警逻辑迁往common/ed_alarm。

ed_ui_vm从ed_snapshot_t/event列表/连接状态生成固定结构，不自行判机械报警。页面对象首次进入时创建，最多保留当前页+最近页；切出销毁或复用，不能每100ms创建新对象。详情页按event_id请求分页快照，不在UI线程读Flash。

图表每条最多120显示点、至多3条曲线；后台聚合降采样；单位与图例静态对象复用。页面过渡≤120ms的平移/淡入，性能不达标直接关闭；无持续旋转/模糊阴影。GUI刷新不等待MQTT/文件/音频。

## 7. 网页与手机

网页延续相同色板/文案，默认1440×900：左侧216px设备列表；主栏状态/趋势；右侧320px事件详情。服务端10设备切换；浏览器收到的是服务端确认状态。

手机390×844：顶部设备选择、状态卡、趋势、事件纵向排列；底部4导航“监测/事件/趋势/设备”，连接与系统放设备页。固定底部确认按钮，留安全区域；不把800×480整体缩小当手机版。

网页断开SSE后5秒显示连接中断；用户仍能看历史，但确认按钮显示不可达原因。重连拉取最新state/event后再开放操作，防止旧revision确认失败被忽略。

## 8. 视觉原型范围与验收

[prototype/index.html](prototype/index.html) 是800×480板端视觉样板，外围按钮切换正常/异常/断网/无基线/静止场景，六页可点击；含基线向导、事件确认和证据查看样例。所有显示值为合成数据。浏览器不是LVGL性能或硬件证据。

验收按03中的T-UI-01..06。必须交付六页实机截图、异常/断线/存储满截图、基线向导录像、200次切页与对象数统计。中文缺字、截断关键单位、过期值显示正常、把MQTT PUBACK当已处理，均属于阻断发布问题。
