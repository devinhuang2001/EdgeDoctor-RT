# EdgeDoctor-RT 电脑版数字孪生控制台验收测试规格

版本 0.1，2026-09-14。状态：待执行。每项初始为 `NOT_RUN`；本文件是验收标准，不表示任何页面或模型已实现。

## 1. 状态、环境与证据

测试状态仅允许 `PASS`、`FAIL`、`MISSING_EVIDENCE`、`NOT_RUN`。`PASS` 必须有原始日志、截图、录屏、性能数据或浏览器自动化结果；模拟数据只能通过 `UNIT`、`API`、`BROWSER` 门禁，不能证明真实板端、真实留证或现场网络表现。

测试层：`UNIT` 为 TypeScript 纯函数/组件测试；`API` 为 FastAPI 与 SQLite 测试；`BROWSER` 为受控 Chromium 自动化；`VIS` 为指定分辨率截图比较；`GPU` 为具备 WebGL 2 的验收电脑；`LAN` 为真实服务和至少一台真实设备。所有报告冻结 git SHA 或未提交差异 hash、Node/浏览器/Python 版本、模型 SHA-256、资产绑定版本、服务端配置摘要和测试数据版本。

证据目录为 `benchmark/results/desktop-dashboard/{run_id}/`，至少包含 `manifest.json`、`case-results.json`、`api.log`、`browser-console.log`、`network.har`、`screenshots/`、`video/`（如有）、`metrics.json` 与 `checksums.txt`。每一条结果包含 `id`、层、前置条件、输入、预期、观察结果、状态和证据相对路径。

统一环境：1920×1080 与 1440×900 Chromium 各一套；1280×720 只验证收紧布局；Windows 桌面验收机开启硬件加速。服务使用隔离 SQLite 数据库和可复现 fixture；LAN 项另外连接真实 API、真实 MQTT 链路和一台已绑定设备。浏览器控制台不得有未处理异常、资源 404 或混合内容错误。

## 3. API、状态与命令语义

| ID | 层 | 操作与输入 | 通过条件与证据 |
|---|---|---|---|
| DD-API-01 | API | 用空库、仅 telemetry、活动事件、恢复未确认、过期事件分别请求状态与汇总 | 页面模型只使用服务端返回状态；`NO_DATA`、`STALE`、`UNKNOWN` 不显示“正常”或伪造在线数 |
| DD-API-02 | API/UNIT | 传入乱序事件 revision、缺字段、非法数值、未知枚举 | schema 校验拒绝或降级为“数据不可用”；不抛未处理异常，不执行客户端诊断推断 |
| DD-API-03 | API/BROWSER | 同时请求设备 A 后快速切到 B，再延迟返回 A | B 页面不得被 A 的状态、趋势或事件覆盖；已取消或过期请求不更新状态仓 |
| DD-API-04 | API/BROWSER | 触发活动未确认事件，点击确认，服务返回 202 后依次模拟 `PENDING`、`APPLIED`、`REJECTED`、`EXPIRED` | 202 只显示已提交；仅 `APPLIED` 显示已应用；拒绝/过期保留可重试解释及事件真实状态 |
| DD-API-05 | API/BROWSER | 触发留证请求，分别返回无证据、CRC 失败、合格元数据和 401 | 仅合格元数据显示下载；401 显示认证需求；其余状态不能称为“原始数据已获取” |
| DD-API-06 | BROWSER | SSE 连通时连续发送 20 条通知，再关闭 SSE | 页面刷新有 250 ms 去抖；断流后 10 秒轮询恢复；无重复刷新风暴或页面崩溃 |
| DD-API-07 | API | 发送 0、29、30、31 秒前的有效遥测和无绑定资产 | 汇总在线状态严格符合冻结阈值；无绑定资产为 `UNKNOWN`，不纳入在线统计 |

## 6. 安全、可靠性与可访问性

|---|---|---|---|

## 7. 放行规则

第一阶段 `/dashboard-v2/` 预览放行：DD-SYS-01..05、DD-API-01..06、DD-3D-01..05、DD-UI-01..07、DD-SEC-01..03、DD-A11Y-01 全部 PASS；DD-3D-06 和 DD-PERF-01 至少有测量记录。任何安全项 FAIL 阻断放行。

切换默认 `/dashboard/` 放行：第一阶段项全部 PASS，且 DD-API-07、DD-3D-06、DD-PERF-01 与至少一台真实绑定设备的 LAN 走查全部 PASS。若信号分析接口未实现，DD-UI-05 的“无分析结果”分支必须 PASS，其余真实证据分析用例可标 `OUT_OF_SCOPE`，不得用模拟频谱替代。

最终报告列出全部 `MISSING_EVIDENCE`、已知限制、测试环境差异和回退步骤。回退只需将根路由恢复到保留的 `/dashboard/`，不删除新版构建产物、绑定配置或验收证据。
